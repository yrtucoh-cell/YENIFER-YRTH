# Red de Contenido Viral — YouTube · TikTok · Instagram

Plan para lanzar **una marca de contenido sin rostro (faceless)** en español, publicada a la vez en
YouTube (Shorts + videos largos), TikTok e Instagram Reels, con el objetivo de generar ingresos
por vistas y, después, por afiliados y patrocinios.

## Resumen en 30 segundos

1. **Nicho elegido:** *"Mente y Dinero"* — psicología del dinero, curiosidades de historia económica
   y errores financieros. Combina el nicho que mejor paga (finanzas) con el que más se comparte
   (psicología/curiosidades).
2. **Los Shorts/TikTok/Reels sirven para crecer, no para cobrar:** pagan céntimos por cada 1.000
   vistas. El dinero real viene de **videos largos de YouTube** + **afiliados**.
3. **Ritmo:** 1 video corto diario (el mismo, adaptado a las 3 plataformas) + 1 video largo semanal.
4. **Meta a 90 días:** 1.000 suscriptores en YouTube y 10.000 seguidores en TikTok para activar
   la monetización.
